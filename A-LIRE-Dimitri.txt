2. DÉPLOIEMENT & CMS :
----------------------
- Dépôt Git : Publie ce dossier directement sur ton dépôt GitHub (branche 'main').
- Netlify : Connecte ton dépôt à Netlify.
- Netlify Identity : Active "Netlify Identity" dans le panneau de configuration Netlify pour autoriser l'accès à /admin.
- Git Gateway : Active le service "Git Gateway" dans Netlify (Settings > Identity > Services).

L'interface d'administration sera désormais accessible directement à l'adresse :
https://ton-site.netlify.app/admin/

Si tu as la moindre question, n'hésite pas !
